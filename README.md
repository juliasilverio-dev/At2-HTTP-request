# 📡 AT2 - HTTP Request

Atividade prática de desenvolvimento web com o objetivo de construir uma página com HTML dinâmico e requisições HTTP para consulta de CEPs.

---

## 📌 Sobre o projeto

Este projeto demonstra como realizar requisições HTTP para APIs externas, interpretando respostas e trabalhando com dados retornados (geralmente em JSON).

As requisições HTTP são fundamentais para comunicação entre sistemas web, utilizando métodos como GET, POST, PUT e DELETE.
